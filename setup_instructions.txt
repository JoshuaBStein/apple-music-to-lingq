  Setup (one-time)                                                                                                    
                  
  1. Install dependencies                                                                                             
  cd /Users/joshuastein/Documents/Python/AppleMusicLyricGrabber                                                       
  python3 -m venv venv                                         
  source venv/bin/activate                                                                                            
  pip install -r requirements.txt                                                                                   
                                 
  2. Configure the script
                                                                                                                      
  Open lyric_lingq.py and set the two constants at the top:                                                           
  LINGQ_API_KEY  = "YOUR_LINGQ_API_KEY"   # https://www.lingq.com/accounts/apikey/                                    
  LINGQ_LANGUAGE = "es"                   # change to your target language code                                       
                                                                                                                    
  3. Run it                                                                                                           
  source venv/bin/activate
  python3 lyric_lingq.py                                                                                              
                                                                                                                    
  A ♪ icon appears in your macOS menu bar.                                                                            
   
  ---                                                                                                                 
  How to use                                                                                                        
                                                                                                                      
  1. Play a song in Apple Music
  2. Click ♪ in the menu bar → Import Current Song → LingQ                                                            
  3. macOS notifications will walk you through: fetching lyrics → importing → done                                    
                                                                                                                      
  The lesson lands in your LingQ library under the language you configured, private by default.
